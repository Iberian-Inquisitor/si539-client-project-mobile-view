# SI 539 Client Project: Mobile View

A four-page UMSI Engaged Learning resource guide for the SI 539 mobile deliverable.

Website: https://iberian-inquisitor.github.io/si539-client-project-mobile-view/

Pages: Home, Preparing, Starting, and During.

## Sources and assistance

- Course starter: https://github.com/UMSIComplexWebDesign/client_project_starter_f26
- Content also reuses the student's first client-project deliverable.
- CSS reset: HTML5 Doctor Reset Stylesheet v1.6.1, Richard Clark, http://html5doctor.com/html-5-reset-stylesheet/
- Branding: https://brand.umich.edu/
- Images were supplied for this course project and are not offered as reusable assets.
- OpenAI Codex assisted with design exploration, HTML/CSS implementation, content revisions, image optimization, and accessibility improvements. The student directed design decisions and reviewed the work.
- Codex selected the Grid sizing approach and rem values, including the 3.5rem logo column, the 17rem content-card minimum, and the 2.2rem step-number column. Here, rem is relative to the root font size. Minimal source comments in the HTML and CSS identify this assistance and the reset source.

## Deployment 2

Restored the required source-attribution comments and documented Codex's Grid and rem sizing decisions. The page content, layout rules, and images are unchanged from the first deployment.

## Accessibility checks

WAVE reported no errors across the four pages. Axe reported no issues on Preparing, Starting, or During. Home retains two reported ARIA issues generated inside YouTube's embedded player. The writeup documents these third-party issues. HTML validation, keyboard navigation, visible focus, skip links, and narrow-screen reflow were checked; Preparing was also checked at 400% browser zoom.
